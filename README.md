# FlamingoHelper Legal Pages

This repository contains the Terms of Service and Privacy Policy for FlamingoHelper.

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `flamingo-helper-legal`.
2. Upload `index.html`, `terms.html`, and `privacy.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish the site.

Expected URLs (available after Pages finishes publishing):
- https://yahyahasnaoui390-netizen.github.io/flamingo-helper-legal/terms.html
- https://yahyahasnaoui390-netizen.github.io/flamingo-helper-legal/privacy.html

Before submitting these URLs to Discord, review the policy against the Bot's actual data collection and add a real support contact.
